# Bots4Velo v3.0.3

修复 AuthMe 登录成功后，机器人已经位于目标服务器却不断请求切服、导致 Velocity 控制台刷屏的问题（#3，PR #4）。

- 切服前查询 Velocity 实际后端，已到目标则取消重试并继续登录后命令。
- 不再把其他后端的协议状态变化误判为到达目标；暂时查不到玩家时继续等待。
- 首次请求保留 INFO，重复请求降为 DEBUG，每 20 次未完成请求发出 WARN。
- 增加 11 项切服/日志回归测试，修正 Windows 换行符导致的工作流测试失败。

## 下载

- `bots4velo-3.0.3.jar`：Velocity 主插件。
- `bots4velo-paper-3.0.3.jar`：配套 Paper 插件；本修复不涉及 Paper 侧代码，现有兼容 companion 无需为此更新。
- 每个 JAR 均附 `.sha256` 校验文件。

## 更新与影响

备份旧 JAR 和插件数据目录，在维护窗口正常停止 Velocity 后替换主插件，确保 plugins 中只有一个 Bots4Velo 主插件 JAR，再启动代理。重启代理会断开所有经由该代理的玩家和机器人；无需重启宿主机或后端服。`/vbot reload` 不会加载新的 JAR 代码。

本版本从仓库公开 3.0.x 维护线发布。已观察到某部署使用源码来源尚未核对的 3.1.0；这类部署应先核对差异并移植修复，不能把 3.0.3 自动视为 3.1.0 的等价升级。

发布 GitHub Release 不会更新任何生产服务器。生产现场验收须在实际部署后进行。详细更新与回滚说明见 [Issue #3 说明](../issue-3-authme-server-switch.md)。
