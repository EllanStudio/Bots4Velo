# Bots4Velo v3.0.6

This patch adds the Chinese AuthMe success-message forms used by the
production `messages_zhcn.yml` configuration.  AuthMe emits messages such as
`*** 已成功登录 ***` and `*** 已成功注册 ***`; the core now recognizes those
forms as confirmation after the command has actually been accepted.

The existing fail-closed authentication state machine is unchanged:

```text
PLAY -> account-state prompt -> login/register -> confirmed success -> AUTHENTICATED
```

`PLAY` and command submission alone still do not authorize rental server
switching.  Existing AuthMeUI, Jail BOT, reconnect, and generation guards are
preserved.
