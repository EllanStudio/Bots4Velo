# Bots4Velo v3.0.5

This patch exposes the confirmed authentication state through the addon-facing
bot snapshot.  Rental and other addons can now recover a positive AuthMe/VeloAuth
state after an addon reload, even when the `AUTHENTICATED` event was emitted
before the listener was registered.

## Changes

- `BotSnapshot` and `AddonBotSnapshot` include `authenticationComplete`.
- `CoreAddonBotService` maps the core's fail-closed authentication state into
  the addon API.
- Existing snapshot constructors remain source-compatible and default the new
  bit to `false`.
- No authentication state is inferred from `PLAY`; only confirmed core state
  can set the bit.
