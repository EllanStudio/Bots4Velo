# Bots4Velo v3.0.9

This release adds Minecraft 26.3 (protocol 777) support.

## Changes

- Add a `modern-26_3` transport adapter built on MCProtocolLib 26.3.
  `protocol-version: "26.3"` and `AUTO` detection of protocol 777 now select it.
- 26.3 replaced the serverbound swing packet with a hand-less punch packet
  and extended teleport acknowledgements with the resolved position. These
  packets now come from a per-version compatibility class, so the 1.21.11,
  26.1.2 and 26.2 adapters send exactly what they sent before.
- On 26.3 the bot follows every position packet (teleport acknowledgement or
  movement) with a client tick end. 26.3 servers kick clients that send two
  position packets in one client tick with "Invalid move player packet
  received".
- Relocate MCProtocolLib's NBT text serializer (`org.geysermc.adventure`)
  inside each modern adapter. It was previously unrelocated, so only one
  copy survived in the merged plugin JAR.

## Requirements

Bots connect through the Velocity proxy itself, so 26.3 bots need a Velocity
build that supports 26.3. Velocity 3.x stops at 26.2 and rejects 26.3 clients
with `outdated_client`; Velocity 4.x supports 26.3 and requires Java 25.

## Verification

CI covers 1.16.5, 1.21.11, 26.1.2, 26.2 and 26.3 protocol contracts and runs
the disposable network integration for each. 26.3 is tested against Paper
26.3 beta builds on Velocity 4.2.1-SNAPSHOT, because Paper has not published a
stable 26.3 build yet.
