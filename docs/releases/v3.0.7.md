# Bots4Velo v3.0.7

This patch normalizes AuthMe authentication text from every modern Minecraft
chat channel supported by MCProtocolLib 26.2. AuthMe success and prompt text
can arrive as system chat, signed player chat, disguised chat, title,
subtitle, or action-bar text depending on server and chat decoration settings.

All variants now use the same plain-text matcher path, so a confirmed AuthMe
message can transition the bot to `AUTHENTICATED` and unblock the rental
server switch. Overlay system chat remains observable for authentication
matching; non-authentication behavior is unchanged.
