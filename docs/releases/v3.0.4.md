# Bots4Velo v3.0.4

修复租赁 BOT 在 AuthMe 6 / VeloAuth 会话恢复场景中反复出现
`AUTHENTICATION_PENDING` 的问题。

- `auth.mode: AUTO` 现在只在观察到 AuthMe login/register prompt 后提交对应命令，不再使用定时的 login → register 盲切换。
- 未填写 prompt 列表的 bot（包括 bot-rental 池）自动使用 AuthMe chat prompt 默认规则。
- 自定义 `success-messages` 会保留内置的 AuthMe 会话恢复成功短语；显式空列表仍保持 fail-closed 语义。
- `AUTHENTICATED`、`SERVER_SWITCH_REQUESTED`、`SERVER_SWITCH_ACCEPTED` 事件分别在状态真正落地时发出，供 addon 做可靠门控。
- 保留 AuthMeUI / Jail BOT 的既有结构化 UI 流程与连接代际隔离。
